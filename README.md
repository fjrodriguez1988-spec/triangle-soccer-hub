# Triangle Pickup Soccer Hub

Static front end for the Triangle Pickup Soccer Hub — a weekly, town-by-town
guide to free and paid pickup soccer across the Triangle (Raleigh, Cary,
Wendell, Zebulon, Wake Forest, Garner, Knightdale, Apex, Morrisville, Durham,
Clayton).

Public, generic content only — no client or business data lives here. This
repo exists purely to host `index.html` via GitHub Pages.

Rebuilt weekly by the `triangle-soccer-hub` skill in the team's private repo.
